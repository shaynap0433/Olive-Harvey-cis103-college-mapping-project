Mapping U.S. Colleges and Universities with Python and Folium

Student project · Python data handling and mapping · Estimated time: 3 to 5 hours

Project goal: Import a real-world dataset of U.S. postsecondary institutions, trim it to the columns you need, show it as a table, plot every institution on an interactive Folium map, and then build a menu that lets a user filter the map by typing in their choices.

1. Background

The U.S. Department of Education publishes data on every college, university, and trade school through the Integrated Postsecondary Education Data System (IPEDS). Each record includes the school's name, state, level, sector, whether it is a Historically Black College or University (HBCU), and its map coordinates.

Data like this is only useful if people can explore it. In this project you act as a data analyst who cleans a large file and turns it into a map a non-programmer could use.

2. Learning objectives

  • Import data from a CSV, TXT, or JSON file using either Python file handling or the Pandas library.

  • Create an interactive map with Folium and add markers with pop-up information.
  • Collect user input with prompts and use it to filter a DataFrame.
  • Rebuild a map from filtered data and handle cases where nothing matches.

Read this before you code: the coordinate names are swapped.

This assignment asks you to rename the longitude column to lat and the latitude column to lon. Follow the instruction exactly, but be careful: lat now holds longitude values and lon holds latitude values. Folium expects locations in the order [latitude, longitude], so you must pass [row['lon'], row['lat']] to the marker. If your markers appear in the ocean or in Antarctica, the values are in the wrong order.

In your write-up (Part 8), add one or two sentences explaining why the swapped names could cause bugs in a real project.

import pandas as pd

# 1. Import
try:
    df = pd.read_csv("colleges.csv")

# 2. Extract, rename, clean
cols = ["INSTNM", "STABBR", "ICLEVEL", "SECTOR", "HBCU", "LONGITUD", "LATITUDE"]
df = df[cols].rename(columns={"LONGITUD": "lat", "LATITUDE": "lon"})
# ...drop missing values, reset index...

# 3. Display table BEFORE the map
display(df.head(20))      # or print(df.head(20).to_string())

# 4. Map function
def build_map(data):
    m = folium.Map(location=[39.8, -98.6], zoom_start=4)
    for _, row in data.iterrows():
        # NOTE: 'lon' holds latitude and 'lat' holds longitude
        folium.Marker([row["lon"], row["lat"]],
                      popup=f"{row['INSTNM']} ({row['STABBR']})").add_to(m)
    return m
